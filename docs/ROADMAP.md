# Product Roadmap

## North-star question

**Which Japanese technology / product / business-model signals are early enough
to matter, relevant enough to Taiwan, and actionable enough for a solo builder?**

## v0.1
Transparent rule-based ranking before AI.

## v0.2
Semantic clustering: one real-world event should become one signal.

## v0.3
Collect Taiwan-side evidence and estimate market-presence gaps.

## v0.4
Use an LLM only after retrieval to produce evidence-backed Opportunity Cards.

## v0.5 moat
Collect human feedback:

- Save
- Ignore
- Ignore reason
- Built / did not build
- Later appeared in Taiwan?

These labels become proprietary ranking data.
